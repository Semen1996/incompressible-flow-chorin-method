# Течение в каверне с движущейся крышкой (метод Чорина)

Двумерное течение вязкой несжимаемой жидкости в квадратной каверне, верхняя крышка которой движется с постоянной скоростью. Уравнения Навье–Стокса решаются методом проекции Чорина на разнесенной (MAC) сетке. Код написан на GNU Octave и совместим с MATLAB.

Дискретизация следует книге Griebel, Dornseifer, Neunhoeffer, _Numerical Simulation in Fluid Dynamics_. Подробное описание физики и численного метода — в [physics.md](physics.md).

## Запуск

```sh
octave --no-gui main.m
```

Откроется окно с heatmap модуля скорости `|v|`, которое обновляется каждые `num.plotEvery` шагов. На диск ничего не сохраняется.

`main.m` — скрипт, поэтому при запуске из интерактивной сессии `octave` поля `u`, `v`, `p` остаются в рабочем пространстве для дальнейшего анализа.

## Параметры

Все параметры задаются в начале [main.m](main.m).

Физические (`prm`):

| Параметр | Значение | Смысл |
|---|---|---|
| `rho`  | 880 кг/м³     | плотность |
| `nu`   | 1.2·10⁻³ м²/с | кинематическая вязкость |
| `L`, `H` | 0.2 м       | размеры каверны |
| `uLid` | 6 м/с         | скорость крышки |
| `tEnd` | 1 с           | время расчета |

При этих значениях число Рейнольдса `Re = uLid·L/nu = 1000`.

Численные (`num`):

| Параметр | Значение | Смысл |
|---|---|---|
| `nx`, `ny`  | 100 | число ячеек по x и y |
| `cfl`       | 0.9 | коэффициент запаса по шагу времени |
| `plotEvery` | 200 | период отрисовки, шагов |

## Метод

На каждом шаге по времени:

1. **Шаг по времени** — `dt` выбирается из условий устойчивости для диффузии и конвекции (CFL), там же вычисляется вес противопоточной добавки `gammaDC`.
2. **Предиктор** — промежуточная скорость `u*` по явной схеме без учета давления: диффузия плюс конвекция в консервативной форме (смесь центральной и donor-cell схем).
3. **Давление** — уравнение Пуассона `Δp = ρ/dt · div u*` с условием `∂p/∂n = 0`. Матрица собирается один раз и раскладывается в разреженное LU, дальше каждый шаг — прямое решение без итераций.
4. **Корректор** — `u = u* − dt/ρ · ∇p`, после чего поле скорости бездивергентно с точностью до ошибок округления.

## Расположение величин на сетке

Индексы массивов — `(j, i)` = (y, x), **строка 1 — низ** каверны.

| Поле | Размер | Где лежит |
|---|---|---|
| `u` | `(ny+2, nx+1)` | вертикальные грани; столбцы 1 и end — на боковых стенках, строки 1 и end — фиктивные |
| `v` | `(ny+1, nx+2)` | горизонтальные грани; строки 1 и end — на дне и крышке, столбцы 1 и end — фиктивные |
| `p` | `(ny, nx)`     | центры ячеек, без фиктивных ячеек |
