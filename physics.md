# Метод Чорина для течения в каверне с движущейся крышкой

Документ описывает физическую постановку и численный метод, реализованные в этом проекте: уравнения, разнесенную сетку, схему расщепления Чорина, дискретизацию слагаемых, граничные условия, выбор шага по времени и решение уравнения Пуассона для давления. Дискретизация следует книге Griebel, Dornseifer, Neunhoeffer,
_Numerical Simulation in Fluid Dynamics_ (далее — «Грибель»); отличия от нее оговорены отдельно.

---

## 1. Постановка задачи

### 1.1. Уравнения

Течение вязкой несжимаемой жидкости описывается уравнениями Навье–Стокса:
$$
\nabla\cdot\mathbf{\vec{u}} = 0,
$$
$$
\frac{\partial \mathbf{\vec{u}}}{\partial t} + (\mathbf{\vec{u}}\cdot\nabla)\mathbf{\vec{u}}
= -\frac{1}{\rho}\nabla p + \nu\,\Delta\mathbf{\vec{u}},$$

где $\mathbf{\vec{u}} = (u, v)$ — скорость, $p$ — давление, $\rho$ — плотность, $\nu$ — кинематическая вязкость.
Массовые силы отсутствуют.

Поскольку $\nabla\cdot\mathbf{\vec{u}} = 0$, конвективный член можно записать в **консервативной** форме,
которая и используется в коде:

$$
(\mathbf{u}\cdot\nabla)u = \frac{\partial (u^2)}{\partial x} + \frac{\partial (uv)}{\partial y},
\qquad
(\mathbf{u}\cdot\nabla)v = \frac{\partial (uv)}{\partial x} + \frac{\partial (v^2)}{\partial y}.
$$

Особенность несжимаемой постановки: у давления нет собственного эволюционного уравнения.
Оно играет роль множителя Лагранжа, который в каждый момент времени «подстраивается» так,
чтобы поле скорости оставалось бездивергентным. Метод Чорина использует именно это свойство.

### 1.2. Область и граничные условия

Прямоугольная каверна $[0, L]\times[0, H]$. Все четыре стенки непроницаемы, на них выполняется
условие прилипания; верхняя стенка (крышка) движется вдоль себя со скоростью $U_\text{lid}$:

| Стенка          | $u$            | $v$ |
| --------------- | -------------- | --- |
| Левая, $x = 0$  | $0$            | $0$ |
| Правая, $x = L$ | $0$            | $0$ |
| Дно, $y = 0$    | $0$            | $0$ |
| Крышка, $y = H$ | $U_\text{lid}$ | $0$ |

Начальное условие — покой: $\mathbf{u}(x, y, 0) = 0$ (крышка трогается мгновенно в момент $t = 0$).

Для давления физических граничных условий нет; численное условие $\partial p/\partial n = 0$
возникает из самого метода (см. раздел 5.2).

### 1.3. Параметры расчета

Значения из `main.m`:

| Параметр                | Обозначение     | Значение               |
| ----------------------- | --------------- | ---------------------- |
| Плотность               | $\rho$          | 880 кг/м³              |
| Кинематическая вязкость | $\nu$           | $1.2\cdot10^{-3}$ м²/с |
| Размеры каверны         | $L\times H$     | 0.2 × 0.2 м            |
| Скорость крышки         | $U_\text{lid}$  | 6 м/с                  |
| Время расчета           | $t_\text{end}$  | 5 с                    |
| Сетка                   | $n_x\times n_y$ | 110 × 100 ячеек        |

Определяющий безразмерный параметр — число Рейнольдса

$$
\mathrm{Re} = \frac{U_\text{lid}\, L}{\nu} = \frac{6\cdot 0.2}{1.2\cdot10^{-3}} = 1000,
$$

т. е. это классический тестовый режим каверны при $\mathrm{Re} = 1000$
(для сравнения есть эталонные данные Ghia, Ghia, Shin, 1982).

Плотность на поле скорости **не влияет**: при постоянной $\rho$ в уравнения входит только
$p/\rho$. Величина $\rho$ нужна лишь для того, чтобы давление получилось в паскалях.

## 2. Разнесенная (MAC) сетка

Область разбита на $n_x\times n_y$ одинаковых ячеек с шагами
$\Delta x = L/n_x$, $\Delta y = H/n_y$ (`createGrid`). Неизвестные хранятся в разных точках ячейки:

- $p$ — в центре ячейки;
- $u$ — в центрах вертикальных граней (левой/правой);
- $v$ — в центрах горизонтальных граней (нижней/верхней).

```
          v(j+1,i)
     +-------o-------+
     |               |
u(j,i) o     * p     o u(j,i+1)
     |               |
     +-------o-------+
          v(j,i)
```

Такое расположение («marker-and-cell», Harlow & Welch, 1965) дает три важных свойства:

1. Разность давлений соседних ячеек попадает ровно на грань, где лежит соответствующая
   компонента скорости, — градиент давления вычисляется без интерполяции.
2. Дивергенция скорости в ячейке — это разность потоков через ее грани, тоже без интерполяции.
3. Не возникает «шахматных» (checkerboard) осцилляций давления, характерных для совмещенных сеток.

### 2.1. Массивы и индексы

Порядок индексов `(j, i)` = (y, x), **строка 1 — низ**. Координаты узлов
(в индексах массивов Octave, начиная с 1):

| Массив | Размер                 | Координаты узла `(j, i)`                               | Граничные слои                                                 |
| ------ | ---------------------- | ------------------------------------------------------ | -------------------------------------------------------------- |
| `u`    | $(n_y+2)\times(n_x+1)$ | $x = (i-1)\Delta x,\; y = (j-\tfrac32)\Delta y$        | столбцы 1, end — на боковых стенках; строки 1, end — фиктивные |
| `v`    | $(n_y+1)\times(n_x+2)$ | $x = (i-\tfrac32)\Delta x,\; y = (j-1)\Delta y$        | строки 1, end — на дне и крышке; столбцы 1, end — фиктивные    |
| `p`    | $n_y\times n_x$        | $x = (i-\tfrac12)\Delta x,\; y = (j-\tfrac12)\Delta y$ | нет                                                            |

Неизвестными (обновляемыми схемой) являются только внутренние узлы:

- `u(jU, iU)`, `jU = 2 : ny+1`, `iU = 2 : nx`;
- `v(jV, iV)`, `jV = 2 : ny`, `iV = 2 : nx+1`.

Все остальные значения — на стенках и в фиктивных слоях — задает только `applyVelocityBC`.

Фиктивные (ghost) ячейки нужны потому, что на стенке, параллельной данной компоненте
скорости, узлов этой компоненты нет: например, узлы `u` ближайшие ко дну лежат на высоте
$\Delta y/2$. Чтобы выписать для них пятиточечный шаблон, добавляется строка-«зеркало» на
высоте $-\Delta y/2$.

Давление фиктивных ячеек не имеет: условие $\partial p/\partial n = 0$ встроено прямо в
матрицу (раздел 6.1).

## 3. Схема Чорина (метод проекции)

### 3.1. Идея

Метод предложен А. Чориным (1968) и независимо Р. Темамом (1969). Шаг по времени
$t^n \to t^{n+1} = t^n + \Delta t$ расщепляется на две части:

1. сначала скорость продвигается по времени **без давления** — получается промежуточное поле
   $\mathbf{u}^*$, которое, вообще говоря, не бездивергентно;
2. затем $\mathbf{u}^*$ **проецируется** на пространство бездивергентных полей добавлением
   градиента давления.

Математическая основа — разложение Гельмгольца–Ходжа: любое достаточно гладкое поле
единственным образом раскладывается в сумму бездивергентного поля (с заданной нормальной
компонентой на границе) и градиента скалярной функции:
$\mathbf{u}^* = \mathbf{u}^{n+1} + \frac{\Delta t}{\rho}\nabla p^{n+1}$.

### 3.2. Три этапа

**Этап 1. Предиктор** (`predictVelocity`) — явный шаг Эйлера по конвекции и диффузии:

$$
\frac{\mathbf{u}^* - \mathbf{u}^n}{\Delta t}
= \nu\,\Delta\mathbf{u}^n - \big[(\mathbf{u}\cdot\nabla)\mathbf{u}\big]^n .
$$

В обозначениях Грибеля это величины $F$ и $G$: `uStar` $= F$, `vStar` $= G$.

**Этап 2. Уравнение Пуассона для давления** (`solvePressure`).
Требуем, чтобы скорость после коррекции была бездивергентной:

$$
\mathbf{u}^{n+1} = \mathbf{u}^* - \frac{\Delta t}{\rho}\nabla p^{n+1},
\qquad \nabla\cdot\mathbf{u}^{n+1} = 0
\quad\Longrightarrow\quad
\Delta p^{n+1} = \frac{\rho}{\Delta t}\,\nabla\cdot\mathbf{u}^* .
$$

**Этап 3. Корректор** (`correctVelocity`):

$$
\mathbf{u}^{n+1} = \mathbf{u}^* - \frac{\Delta t}{\rho}\nabla p^{n+1},
$$

после чего заново выставляются граничные значения (`applyVelocityBC`).

### 3.3. Алгоритм одного шага (`main.m`)

```
пока t < tEnd:
    [dt, gammaDC] = computeTimeStep(u, v)          % устойчивость
    dt = min(dt, tEnd - t)                          % точно попасть в tEnd
    [uStar, vStar] = predictVelocity(u, v, dt, gammaDC)
    p = solvePressure(uStar, vStar, dt)             % Пуассон, прямой решатель
    [u, v] = correctVelocity(uStar, vStar, p, dt)   % + applyVelocityBC
    t = t + dt
```

Перед циклом один раз выполняются `createGrid`, начальное условие с `applyVelocityBC`
и `buildPressureSolver` (сборка и LU-разложение матрицы давления).

### 3.4. Свойства схемы

- **Порядок по времени — первый**: явный Эйлер в предикторе плюс ошибка расщепления
  $O(\Delta t)$. Это «неинкрементальный» вариант Чорина: в предикторе давление с прошлого
  шага не используется вовсе, $p$ на каждом шаге вычисляется заново.
- **Давление — вспомогательная величина.** Полученное $p$ — это ровно то поле, которое
  обеспечивает $\nabla\cdot\mathbf{u}^{n+1}=0$; оно приближает физическое давление с
  точностью $O(\Delta t)$ и имеет численный пограничный слой у стенок из-за искусственного
  условия $\partial p/\partial n = 0$.
- **Бездивергентность выполняется точно на дискретном уровне** (с точностью до округления),
  потому что матрица давления — это в точности композиция дискретных операторов
  «дивергенция ∘ градиент», применяемых в `solvePressure` и `correctVelocity` (раздел 5.3).
- Стационарное решение, если к нему сходится процесс, удовлетворяет дискретной стационарной
  задаче, и его точность определяется только пространственной дискретизацией.

## 4. Пространственная дискретизация

Ниже используются «физические» полуцелые индексы: $u_{i+1/2,\,j}$ — скорость на правой грани
ячейки $(i, j)$, $v_{i,\,j+1/2}$ — на верхней, $p_{i,j}$ — в центре.

### 4.1. Диффузия

Пятиточечный лапласиан (`discreteLaplacian`), второй порядок точности:

$$
(\Delta u)_{i+1/2,j} \approx
\frac{u_{i+3/2,j} - 2u_{i+1/2,j} + u_{i-1/2,j}}{\Delta x^2}
+ \frac{u_{i+1/2,j+1} - 2u_{i+1/2,j} + u_{i+1/2,j-1}}{\Delta y^2},
$$

аналогично для $v$. У стенок шаблон захватывает узлы на стенке или фиктивные узлы,
поэтому значения на границе должны быть выставлены до вызова предиктора.

### 4.2. Конвекция: смесь центральной и donor-cell схем

Каждая конвективная производная записывается как разность потоков через грани контрольного
объема вокруг узла скорости, например

$$
\left.\frac{\partial (u^2)}{\partial x}\right|_{i+1/2,j}
\approx \frac{F_E - F_W}{\Delta x},
\qquad
\left.\frac{\partial (uv)}{\partial y}\right|_{i+1/2,j}
\approx \frac{F_N - F_S}{\Delta y}.
$$

Поток через грань (`donorCellFlux`) зависит от **переносящей скорости** $a$ на этой грани и
от значений **переносимой величины** $\varphi_L, \varphi_R$ по обе стороны от нее:

$$
F = a\,\frac{\varphi_L + \varphi_R}{2} \;+\; \gamma\,|a|\,\frac{\varphi_L - \varphi_R}{2}.
$$

- $\gamma = 0$ — центральная схема (второй порядок, но неустойчива/осциллирует при
  больших сеточных числах Рейнольдса);
- $\gamma = 1$ — схема donor-cell (противопоточная, первый порядок): при $a > 0$ поток равен
  $a\varphi_L$, при $a < 0$ — $a\varphi_R$, т. е. величина берется «из ячейки-донора»
  выше по потоку;
- промежуточные $\gamma$ дают линейную смесь. Противопоточная добавка эквивалентна
  искусственной вязкости $\sim\gamma|a|\Delta x/2$.

Переносящие скорости берутся средним арифметическим двух ближайших узлов. Для уравнения $u$:

$$
u_E = \tfrac12\big(u_{i+1/2,j} + u_{i+3/2,j}\big),\quad
u_W = \tfrac12\big(u_{i-1/2,j} + u_{i+1/2,j}\big),
$$

$$
v_N = \tfrac12\big(v_{i,j+1/2} + v_{i+1,j+1/2}\big),\quad
v_S = \tfrac12\big(v_{i,j-1/2} + v_{i+1,j-1/2}\big),
$$

для уравнения $v$ — симметрично. Это в точности схема Грибеля (формулы 3.19–3.20 книги),
лишь записанная через функцию потока.

Консервативная форма гарантирует, что поток, вышедший из одного контрольного объема,
входит в соседний, — импульс не порождается и не теряется схемой внутри области.

**Почему нужна противопоточная добавка.** Сеточное число Рейнольдса у крышки
$\mathrm{Re}_h = U_\text{lid}\Delta x/\nu \approx 6\cdot 1.8\cdot10^{-3}/1.2\cdot10^{-3} \approx 9 > 2$,
а при $\mathrm{Re}_h > 2$ чистая центральная схема дает нефизичные пилообразные осцилляции.

### 4.3. Дивергенция и градиент

Дивергенция $\mathbf{u}^*$ в центре ячейки (`solvePressure`):

$$
(\nabla\cdot\mathbf{u}^*)_{i,j} =
\frac{u^*_{i+1/2,j} - u^*_{i-1/2,j}}{\Delta x}
+ \frac{v^*_{i,j+1/2} - v^*_{i,j-1/2}}{\Delta y}.
$$

Градиент давления на гранях (`correctVelocity`):

$$
\left(\frac{\partial p}{\partial x}\right)_{i+1/2,j} = \frac{p_{i+1,j} - p_{i,j}}{\Delta x},
\qquad
\left(\frac{\partial p}{\partial y}\right)_{i,j+1/2} = \frac{p_{i,j+1} - p_{i,j}}{\Delta y}.
$$

В коде это `diff(p, 1, 2)` и `diff(p, 1, 1)`; они дают ровно $(n_y)\times(n_x-1)$ и
$(n_y-1)\times(n_x)$ значений — по числу внутренних узлов `u` и `v`.
Градиент на гранях, лежащих на стенках, не вычисляется — там скорость задана.

## 5. Граничные условия

### 5.1. Скорость (`applyVelocityBC`)

Условия делятся на два типа в зависимости от того, лежит ли узел на стенке.

**Компонента, нормальная к стенке** — узлы лежат прямо на стенке, условие ставится
непосредственно (непроницаемость):

$$
u_{1/2,\,j} = u_{n_x+1/2,\,j} = 0 \quad\text{(боковые стенки)},\qquad
v_{i,\,1/2} = v_{i,\,n_y+1/2} = 0 \quad\text{(дно и крышка)}.
$$

**Компонента, касательная к стенке** — узлов на стенке нет, ближайший внутренний узел
отстоит от нее на полшага. Условие прилипания ставится через фиктивный узел так, чтобы
**среднее** фиктивного и внутреннего значений равнялось скорости стенки
(линейная интерполяция на стенку):

$$
\frac{u_\text{ghost} + u_\text{inner}}{2} = u_\text{wall}
\quad\Longrightarrow\quad
u_\text{ghost} = 2u_\text{wall} - u_\text{inner}.
$$

| Где                | Код                              | Смысл                       |
| ------------------ | -------------------------------- | --------------------------- |
| Дно, $u$           | `u(1,:) = -u(2,:)`               | $u = 0$ на $y=0$            |
| Крышка, $u$        | `u(end,:) = 2*uLid - u(end-1,:)` | $u = U_\text{lid}$ на $y=H$ |
| Левая стенка, $v$  | `v(:,1) = -v(:,2)`               | $v = 0$ на $x=0$            |
| Правая стенка, $v$ | `v(:,end) = -v(:,end-1)`         | $v = 0$ на $x=L$            |

Такая аппроксимация имеет второй порядок по $h$ для значения на стенке; касательное
напряжение (производная) у стенки при этом аппроксимируется с первым порядком.

**Когда вызывается.** `applyVelocityBC` вызывается при задании начального условия и в конце
`correctVelocity`, т. е. на вход предиктору всегда приходит поле с актуальными граничными
и фиктивными значениями. Внутри шага предиктор и корректор пишут только во внутренние узлы
(`jU, iU` / `jV, iV`), поэтому в `uStar`, `vStar` граничные значения скопированы из
`u^n`, `v^n` без изменений — это существенно для условия на давление (см. ниже).

**Угловые особенности.** В верхних углах скорость разрывна: на крышке $u = U_\text{lid}$,
на боковой стенке $u = 0$. Точное решение имеет там сингулярность давления и завихренности;
на сетке это проявляется как большие значения $p$ в двух верхних угловых ячейках и
не устраняется сгущением сетки. Это свойство постановки, а не ошибка схемы.
Фиктивные узлы в самих углах массивов (`u(1,1)`, `v(1,1)` и т. п.) в шаблоны внутренних
узлов не входят, и их значения ни на что не влияют.

### 5.2. Давление: откуда берется $\partial p/\partial n = 0$

На стенке нормальная скорость задана и не должна меняться при коррекции. Из
$u^{n+1}_\text{wall} = u^*_\text{wall} - \frac{\Delta t}{\rho}\,\partial p/\partial n$ следует:

- если положить $u^*$ на стенке равным скорости стенки (так сделано и в коде, и у Грибеля:
  $F = u$, $G = v$ на границе), то
  $$\frac{\partial p}{\partial n}\bigg|_\text{wall} = 0 .$$

То есть однородное условие Неймана для давления — прямое следствие выбора граничных значений
промежуточной скорости. Оно не физическое (истинный нормальный градиент давления на стенке
равен $\rho\nu\,\partial^2 u_n/\partial n^2$ и отличен от нуля), что и дает упомянутый
пограничный слой ошибки давления порядка $O(\sqrt{\nu\Delta t})$.

Дискретно: для ячейки у левой стенки в дивергенцию входит поток через стенку
$u^*_{1/2,j} = 0$, а градиент давления на стенке не вычисляется. Это эквивалентно
фиктивному давлению $p_{0,j} = p_{1,j}$, при котором слагаемое
$(p_{0,j} - p_{1,j})/\Delta x^2$ в лапласиане обнуляется. Отсюда коэффициент $-1$ вместо $-2$
на диагонали одномерной матрицы у концов (`neumannSecondDiff`).

### 5.3. Условие совместности и точная бездивергентность

У задачи Неймана $\Delta p = f$, $\partial p/\partial n = 0$ есть решение, только если
$\int f\,d\Omega = 0$. Для дискретной задачи сумма дивергенций по всем ячейкам
телескопируется в суммарный поток через границу:

$$
\sum_{i,j}(\nabla\cdot\mathbf{u}^*)_{i,j}\,\Delta x\Delta y
= \oint \mathbf{u}^*\cdot\mathbf{n}\,ds = 0,
$$

так как нормальная компонента $\mathbf{u}^*$ на всех стенках равна нулю.
Условие совместности выполнено **автоматически** — при любом $\mathbf{u}^*$ из предиктора.

Обозначим через $D$ дискретную дивергенцию (центры ← грани), через $G$ — дискретный градиент
(грани ← центры, только внутренние грани). Матрица давления $A$ из `buildPressureSolver` —
это в точности $A = DG$. Тогда после коррекции

$$
D\mathbf{u}^{n+1} = D\mathbf{u}^* - \frac{\Delta t}{\rho}\,DGp
= D\mathbf{u}^* - \frac{\Delta t}{\rho}\cdot\frac{\rho}{\Delta t}D\mathbf{u}^* = 0
$$

с точностью до ошибок округления. Проверка: $\max|\nabla\cdot\mathbf{u}^{n+1}| \sim 10^{-11}$
(при $\rho/\Delta t \sim 10^6$ это машинная точность относительно правой части).
Если это значение заметно больше, нарушена согласованность $D$, $G$ и $A$ или граничные условия.

## 6. Решение СЛАУ для давления

### 6.1. Сборка матрицы (`buildPressureSolver`)

Неизвестные — $N = n_x n_y$ значений давления (в расчете $N = 11\,000$), упорядоченные
по столбцам массива `p` (быстрее всего меняется $j$, т. е. $y$), как `p(:)` в Octave.

Одномерный оператор второй разности с условием Неймана на концах:

$$
D_n = \begin{pmatrix}
-1 & 1 & & & \\
1 & -2 & 1 & & \\
& \ddots & \ddots & \ddots & \\
& & 1 & -2 & 1 \\
& & & 1 & -1
\end{pmatrix}\in\mathbb{R}^{n\times n}.
$$

Двумерный лапласиан собирается через кронекеровы произведения:

$$
A = \frac{1}{\Delta x^2}\,D_{n_x}\otimes I_{n_y} \;+\; \frac{1}{\Delta y^2}\,I_{n_x}\otimes D_{n_y}.
$$

Порядок множителей в `kron` соответствует упорядочению «$y$ быстрее»: $I_{n_x}\otimes D_{n_y}$
действует внутри каждого столбца `p` (по $y$), $D_{n_x}\otimes I_{n_y}$ — между столбцами (по $x$).
Матрица разреженная, пятидиагональная (≈ $5N$ ненулевых элементов), симметричная,
отрицательно полуопределенная.

### 6.2. Вырожденность и фиксация уровня давления

Ядро $A$ — константы: $A\mathbf{1} = 0$ (давление определено с точностью до константы,
физически значим только градиент). Матрица вырождена, и прямой решатель на ней не работает.

Способ в коде: первое уравнение заменяется на $p_1 = 0$
(`A(1,:) = 0; A(1,1) = 1` в матрице, `rhs(1) = 0` в правой части).

Почему это не искажает решение. Так как $A$ симметрична и $A\mathbf{1}=0$, сумма всех строк $A$
равна нулю, т. е. первая строка — линейная комбинация остальных. Правая часть по разделу 5.3
тоже имеет нулевую сумму, поэтому первое уравнение — следствие остальных $N-1$ уравнений.
Его можно выбросить без потери информации и заменить нормировкой. Полученная система
невырождена, а ее решение удовлетворяет **всем** исходным уравнениям, включая выброшенное.

После решения из $p$ вычитается среднее (`p = p - mean(p, 'all')`), чтобы выдавать давление
с нулевым средним. На скорость это не влияет — сдвиг на константу не меняет градиент.

### 6.3. Прямой метод: разреженное LU-разложение (реализовано)

Ключевое наблюдение: матрица $A$ зависит только от сетки ($n_x, n_y, \Delta x, \Delta y$)
и **не меняется во времени** (плотность постоянна, сетка неподвижна, $\Delta t$ входит только
в правую часть). Поэтому разложение делается **один раз** перед циклом:

```octave
[L, U, P, Q] = lu(A);        % P*A*Q = L*U
```

Для разреженной матрицы Octave использует UMFPACK; перестановки строк $P$ (выбор ведущего
элемента) и столбцов $Q$ (уменьшение заполнения) хранятся вместе с множителями.
На каждом шаге решается $A\mathbf{p} = \mathbf{b}$ двумя треугольными подстановками:

$$
A = P^{T} L U Q^{T}
\quad\Longrightarrow\quad
\mathbf{p} = Q\Big(U^{-1}\big(L^{-1}(P\mathbf{b})\big)\Big),
$$

в коде `p = Q * (U \ (L \ (P * rhs)))`. Оператор `\` распознает треугольную матрицу и делает
прямую/обратную подстановку за $O(\mathrm{nnz}(L) + \mathrm{nnz}(U))$.

Свойства:

- нет итераций, критерия останова и допуска — уравнение решается точно (до округления),
  поэтому дискретная бездивергентность тоже точная;
- стоимость шага — две подстановки; разложение для $N\sim10^4$ занимает доли секунды и
  окупается за первые же шаги (всего шагов — порядка $10^4$);
- память: заполнение $L$, $U$ для двумерной пятиточечной матрицы растет как $O(N\log N)$ —
  для сеток до $\sim10^3\times10^3$ это приемлемо, для очень больших сеток и в 3D прямой
  метод становится дорогим.

### 6.4. Альтернативные методы

| Метод                            | Суть                                                                                                                                                                 | Плюсы                                              | Минусы                                                                                                                    |
| -------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| **SOR** (как у Грибеля)          | Гаусс–Зейдель с верхней релаксацией $\omega\in(1,2)$, итерации до $\|r\| <$ tol; граничные условия — через фиктивные ячейки давления, обновляемые на каждой итерации | Простота, без матриц, мало памяти                  | Медленная сходимость: $O(N)$ итераций при $\omega=1$, $O(\sqrt N)$ при оптимальном $\omega$; остаточная дивергенция ~ tol |
| Якоби / Гаусс–Зейдель            | То же без релаксации                                                                                                                                                 | Тривиальны, Якоби легко векторизуется              | Еще медленнее; на практике — только как сглаживатели в многосеточном методе                                               |
| Red–black SOR                    | SOR с шахматным порядком обхода                                                                                                                                      | Векторизуется и распараллеливается                 | Те же асимптотики, что у SOR                                                                                              |
| **CG / PCG**                     | Сопряженные градиенты для симметричной матрицы $-A$ (прекондиционер — неполное Холецкое `ichol`, многосеточный)                                                      | $O(\sqrt{\kappa})$ итераций, хорошо масштабируется | Нужна симметрия: замена строки 1 ее нарушает (см. ниже)                                                                   |
| Многосеточный (multigrid)        | Сглаживание на иерархии сеток                                                                                                                                        | Оптимальная сложность $O(N)$                       | Сложнее в реализации                                                                                                      |
| **Быстрые преобразования (DCT)** | Для однородной сетки с условиями Неймана $A$ диагонализуется дискретным косинус-преобразованием типа II по каждому направлению                                       | $O(N\log N)$, точное решение                       | Только прямоугольная область, равномерная сетка, постоянные коэффициенты                                                  |
| Холецкий                         | $-A = R^TR$ для симметричной положительно определенной матрицы                                                                                                       | Вдвое меньше памяти и работы, чем LU               | Требует симметричной фиксации уровня                                                                                      |

Замечания:

- **Симметричная фиксация уровня.** Если вместо замены строки обнулить и строку, и столбец 1
  (`A(1,:) = 0; A(:,1) = 0; A(1,1) = 1`), то при $p_1 = 0$ решение не меняется (столбец 1
  умножается на $p_1 = 0$), а матрица остается симметричной. Тогда $-A$ положительно
  определена и применимы `chol` или `pcg`. Другой вариант для итерационных методов — не
  фиксировать уровень вовсе: CG сходится и на вырожденной совместной системе, если правая
  часть ортогональна ядру.
- Для этой задачи (фиксированная матрица, умеренный $N$, двумерная область) разреженный
  прямой метод с однократным разложением практически оптимален по простоте и скорости;
  итерационные методы оправданы при росте сетки или переходе к 3D.

## 7. Шаг по времени (`computeTimeStep`)

Предиктор явный, поэтому шаг ограничен двумя условиями устойчивости.

**Диффузия** (явная схема для уравнения теплопроводности на пятиточечном шаблоне):

$$
\Delta t \le \frac{1}{2\nu}\left(\frac{1}{\Delta x^2} + \frac{1}{\Delta y^2}\right)^{-1}.
$$

**Конвекция** (условие Куранта–Фридрихса–Леви в двумерной форме):

$$
\Delta t\left(\frac{|u|_{\max}}{\Delta x} + \frac{|v|_{\max}}{\Delta y}\right) \le 1.
$$

В коде оба ограничения объединены и умножены на коэффициент запаса `cfl` $= 0.9$:

$$
\Delta t = \frac{\text{cfl}}{\max\!\left(2\nu\left(\dfrac{1}{\Delta x^2}+\dfrac{1}{\Delta y^2}\right),\;
\dfrac{|u|_{\max}}{\Delta x} + \dfrac{|v|_{\max}}{\Delta y}\right)}.
$$

Отличие от Грибеля: там конвективное условие ставится по каждому направлению отдельно
($\Delta t < \Delta x/|u|_{\max}$, $\Delta t < \Delta y/|v|_{\max}$); суммарная форма строже и
надежнее, когда обе компоненты велики одновременно.

При оценке $|u|_{\max}$, $|v|_{\max}$ **фиктивные значения исключаются**: в фиктивной строке над
крышкой $u = 2U_\text{lid} - u_\text{inner}$ может доходить почти до $2U_\text{lid}$, что
занизило бы шаг вдвое без всякой физической причины.

Последний шаг укорачивается (`dt = min(dt, tEnd - t)`), чтобы расчет закончился ровно в $t_\text{end}$.

Ориентировочно для параметров из `main.m`: на старте (жидкость в покое) работает диффузионное
ограничение, $\Delta t \approx 6.8\cdot10^{-4}$ с; после разгона течения — конвективное,
и шаг уменьшается в несколько раз.

**Вес donor-cell.** Одновременно вычисляется

$$
\gamma = \min\!\left(1,\;\max\!\left(\frac{|u|_{\max}\Delta t}{\Delta x},\;\frac{|v|_{\max}\Delta t}{\Delta y}\right)\right),
$$

что соответствует условию устойчивости гибридной схемы у Грибеля
$\gamma \ge \max(|u|\Delta t/\Delta x,\ |v|\Delta t/\Delta y)$. Берется наименьшее допустимое значение —
так схема остается максимально близкой к центральной (менее диссипативной).
Ограничение сверху единицей — страховка: при выполненном условии CFL оно не срабатывает.

## 8. Ограничения и возможные улучшения

- **Порядок по времени — первый.** Для точного переходного процесса можно перейти на
  инкрементальную схему проекции (Ван Кан) с давлением прошлого шага в предикторе и
  схемой второго порядка (Адамс–Башфорт / Кранк–Николсон, BDF2).
- **Явная диффузия** ограничивает шаг как $O(h^2)$; на мелких сетках при умеренных $\mathrm{Re}$
  выгоднее неявная диффузия (еще одна разреженная система на шаг, но с хорошо обусловленной
  матрицей).
- **Схема donor-cell первого порядка** вносит численную вязкость, заметную при больших $\gamma$;
  альтернативы — QUICK, TVD-схемы с ограничителями.
- **Равномерная сетка.** Пограничные слои у стенок и угловые особенности лучше разрешаются на
  сгущающейся к стенкам сетке; это потребует обобщения `discreteLaplacian` и матрицы давления.
- **Проверка результата.** Для $\mathrm{Re}=1000$ при выходе на стационар профили $u$ по
  вертикальной и $v$ по горизонтальной средним линиям можно сравнить с таблицами Ghia et al. (1982);
  для этого `tEnd` нужно увеличить до установления (порядка десятков секунд при текущих
  размерах, т. е. нескольких десятков $L/U_\text{lid}$).
